# Свои источники видео

Сюда можно положить свои источники — приложение подхватит их автоматически при запуске,
менять `main.py` не нужно.

## Как это работает

1. Создайте файл, например `my_source.py` (любое имя, кроме начинающихся с `_`).
2. Определите в нём класс — наследник `VideoSource` — и реализуйте `get_stream_url`.
3. Запустите приложение. В консоли появится строка вида
   `[plugins] подключён источник «...» из my_source.py`.

Класс должен вернуть **прямую ссылку на поток** (`.m3u8`, `.mp4`) — её воспроизведёт
встроенный mpv. `None` означает «у меня этого нет», тогда приложение попробует
следующий источник.

## Что доступно внутри класса

| Что | Как |
|---|---|
| ID аниме Shikimori | приходит первым аргументом `get_stream_url(anime_id, episode, dubbing)` |
| Название тайтла | `self.anime_title` (русское), `self.anime_title_alt` (романдзи), `self.anime_year` |
| Свои озвучки | переопределите `available_dubbings()` — тогда в интерфейсе они станут «рабочими» |
| Свои серии | переопределите `get_episodes(anime_id)` -> `[(номер, название), ...]` |
| Файлы рядом с программой | `BASE_DIR` |
| Кэш/настройки libmpv | ничего не нужно, плеер уже настроен |
| Сеть | `requests` доступен (он в зависимостях) |

## Пример-заготовка

Готовый шаблон с комментариями — в файле `_example_source.py` в этой папке (файлы, начинающиеся с `_`, приложение не загружает — это шаблон).
Скопируйте его, переименуйте и заполните своими запросами.

## Полезно знать

* Тяжёлые запросы не блокируют интерфейс: `get_stream_url` вызывается в отдельном потоке.
* Ошибку лучше вернуть как `None` (в статусной строке появится «источник не нашёл»),
  но и исключение не уронит приложение — оно попадёт в консоль и статусную строку.
* Порядок источников: ваши файлы (библиотека) → AniLibria → плагины → ручные ссылки.
  Побеждает первый, кто вернул ссылку.
* Проверяйте свои источники кнопкой «Открыть URL…» — по ней видно, играет ли поток.
