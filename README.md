# Anime Viewer

Десктопное приложение для просмотра аниме **и чтения манги**: каталог и поиск через
Shikimori, реальные серии из официального API AniLibria, встроенный плеер mpv, каталог
и чтение манги из официального API MangaDex, история просмотров, плагины и настраиваемое
оформление с картинками.

Версия 1.5.

Это **портативная сборка**: устанавливать ничего не нужно — Python, PySide6 и плеер mpv
уже внутри папки. Распакуйте её целиком и запустите `run-detached.bat` (без чёрного окна
консоли); если что-то не работает — `run.bat`, он показывает сообщения об ошибках.
Короткая инструкция лежит в файле `КАК ЗАПУСТИТЬ.txt`.

Слева список аниме с постерами и полосой просмотра, справа встроенный плеер;
четвёртая вкладка — читалка манги.

## Запуск

**Проще всего:** двойной клик по `run-detached.bat` — приложение откроется без чёрного окна
консоли. Остальные способы:

```
run-detached.bat     — без консоли (обычный способ запуска)
run.bat              — то же, но с консолью: видно сообщения об ошибках
.\run.ps1            — то же из PowerShell
.\run.ps1 --detach   — из PowerShell, без консоли
Создать ярлык на рабочем столе.bat — один раз создаёт ярлык с иконкой приложения
```

Устанавливать ничего не нужно: портативный Python и все библиотеки лежат в папке,
отдельный `.venv` не требуется. Папку можно целиком скопировать на другой компьютер
(или на флешку) — приложение запустится оттуда.

Нужен Windows 10/11 (64 бит) и интернет: каталоги, поиск, серии и страницы манги
берутся из сети. Если Windows предупреждает «Windows защитила ваш компьютер» — это
обычное предупреждение для скачанных из интернета файлов: «Подробнее» →
«Выполнить в любом случае».



## Как пользоваться

**Главная вкладка — «Каталог AniLibria»** (слева): это список аниме, которые озвучила
студия — **1873 релиза**, прямо из их официального API. Каталог грузится сразу при запуске
и работает как основной список:

* сортировка: **Новинки / По рейтингу / По году / По названию**;
* **«Показать ещё»** — следующая страница по 40 релизов;
* карточки с постерами, годом, числом серий, оценкой и жанрами;
* клик по релизу → справа появляются серии и озвучка, дальше как обычно;
* **двойной клик** → сразу включается первая серия;
* релизы, у которых в API нет привязки к Shikimori, всё равно работают: они разрешаются
  напрямую по внутреннему id релиза AniLibria.

Что видно в подписи над списком: `В каталоге AniLibria: 1873 релизов · показано 40`.

Вкладка **«Поиск»** — поиск аниме по названию:

1. Начните вводить название — поиск запускается сам (пауза 550 мс, от 3 символов).
   Enter и кнопка «Найти» тоже работают.
2. Слева карточки: постер, название, «год · тип · серии · оценка» и полоса просмотра.
3. Выберите аниме → справа появится список серий из AniLibria.
4. Выберите серию и озвучку → **Смотреть**. Играет во встроенном плеере.
5. Снизу: пауза, перемотка, время, громкость.
6. **Клик по картинке видео — пауза и продолжить** (как в YouTube); то же делает
   `Space`. Если кликнуть дважды подряд, лишнего переключения не будет — пауза
   поставится один раз.

Кнопки в правой панели: **Смотреть**, **Следующая серия**, **Добавить озвучку**,
а ниже — **Файл…** и **Поток…** (открыть своё видео или ссылку). В шапке: **Продолжить**
(появляется, если есть история), **Оформление**, **Плагины**, **Полный экран**.
Когда окно узкое, логотип и подпись в шапке прячутся, чтобы не обрезались кнопки.

Четвёртая вкладка — **«Манга»**, правая панель переключается на читалку (см. «Манга»).

## Озвучки

В списке озвучек только **рабочие** варианты: озвучка источника (AniLibria) плюс всё,
что вы добавили сами. Нерабочих пунктов в списке нет.

Почему автоматически только AniLibria: это единственный подключённый источник
с официальным API, и там у эпизода одна звуковая дорожка (`hls_480/720/1080`; поля выбора
перевода в API нет). Ссылки других студий (Dream Cast, JAM CLUB, AniDUB, Studio Band,
SHIZA и др.) распространяют сторонние сервисы, поэтому такую озвучку подключаете вы.

**Как добавить озвучку:** кнопка **«Добавить озвучку»** → выбрать или ввести название
студии (список названий правится в `settings.json` → `dubbings`) → вставить ссылку на
поток (`mp4`/`m3u8`) для текущей серии. Если в ссылке написать `{episode}`, она подойдёт
для всех серий. Озвучка сразу появится в списке и будет играть.

Ссылки хранятся в `manual_streams.json` рядом с программой:

```json
{
  "11757|2|AniDUB": "https://example.com/sao-02.m3u8",
  "11757|*|JAM CLUB": "https://example.com/sao/{episode}.m3u8"
}
```

Ключ — `<shikimori_id>|<серия>|<озвучка>`, `*` = все серии.

Если в вашем потоке несколько звуковых дорожек, они появятся в списке с пометкой
«Дорожка …» — переключение меняет дорожку в mpv без перезагрузки файла.

## История просмотров

Вкладка **«История»** слева: постер, название, «серия 2 · AniLibria · 12:30 / 23:43»
и когда смотрели («5 мин назад», «вчера»).

* **Продолжить** (кнопка в шапке или двойной клик по записи) — возвращает аниме, серию
  и озвучку и запускает воспроизведение с сохранённой секунды;
* **Забыть** — сбрасывает позицию у выбранной записи;
* **Убрать** / **Очистить** — удаление записей.

Данные: `history.json` (до 200 записей). Позиция продолжения берётся как максимум из
истории и `progress.json`; прогресс пишется каждые 5 секунд, при паузе, смене серии
и закрытии окна. Если до конца оставалось меньше 15 секунд — серия начнётся с начала.

## Манга (MangaDex)

Четвёртая вкладка слева — **«Манга»**. Источник — официальный API
[MangaDex](https://api.mangadex.org/docs/) (ключ не нужен, регистрация не требуется).

**Готовый список.** Открываете вкладку — сразу видите каталог: **все доступные тайтлы
источника** (у MangaDex это около **55 000** тайтлов, у которых есть главы). Искать
ничего не нужно, поиск нужен только чтобы найти конкретное название.

| Элемент | Что делает |
|---|---|
| **Сортировка** | Популярные · По оценке · Новинки глав · По названию · По году |
| **«только с русским»** | оставляет тайтлы с переводом на русский (около 5 300) |
| **«Каталог»** | возвращает список каталога из результатов поиска |
| **«Показать ещё»** | следующая страница по 40 тайтлов |

В подписи видно, сколько тайтлов всего и сколько уже показано:
`В каталоге MangaDex: 54818 тайтлов · показано 40 · осталось 54778`.

**Как читать:**

1. Выберите тайтл в каталоге — или введите название в строке поиска (можно
   **по-русски**: название уточнится через Shikimori, поиск идёт сам после 550 мс).
2. Справа сразу открывается читалка и список глав. Приложение открывает **первую
   читаемую главу на выбранном языке** — это важно, потому что на MangaDex встречаются
   пустые «главы 0» и прологи без картинок.
3. В строке «Глава» выбирается глава (там же видны команда перевода, язык и число
   страниц), в «Язык» — язык перевода: **Русский** по умолчанию, и если главы на
   русском нет, подставляется английская (можно выключить в «Оформлении»).
4. Читайте лентой (непрерывная прокрутка) или постранично — переключатель
   **«Постранично» / «Лента»** или клавиша `M`.
5. Масштаб страниц — кнопка в панели чтения (на ней короткая подпись: **Ширина**,
   **Высота** или **100%**) или клавиша `W`:
   **По ширине → По высоте → 100%**. Он работает в обоих режимах, а в режиме 100%
   страницу можно увеличить (`+` / `−`) — если она станет больше окна, появятся
   полосы прокрутки. Для чтения «целиком одной страницей» удобны `Постранично` +
   `По высоте`.
6. Кнопка **«Читать»** переоткрывает выбранную главу (например, если часть страниц
   не загрузилась) и **не сбрасывает** место чтения.

**Про лицензированные тайтлы.** У популярных тайтлов (Solo Leveling, «О моём
перерождении в слизь» и других официально изданных) MangaDex оставляет главы без
картинок — страницы доступны только в приложении издателя. Приложение говорит об этом
прямо: «У этого тайтла на MangaDex нет страниц», а кнопка «Браузер» открывает
главу на сайте.

Про русские названия: в MangaDex названия в основном на латинице, поэтому запрос
по-русски сначала уточняется через Shikimori, а затем ищется романдзи-название.
Русское название подставляется только при совпадении названий — чтобы похожие
тайтлы не получили чужое имя.

**Читалка:**

| Действие | Как |
|---|---|
| Следующая / предыдущая страница | `←` / `→`, кнопки у ползунка, ползунок |
| Экран вперёд / назад (в ленте) | `Space`, `PageDown` / `PageUp` |
| Прокрутка | колесо мыши, `↑` / `↓` |
| Следующая / предыдущая глава | `N` (вперёд), кнопки-иконки главы в панели чтения |
| Лента ↔ постранично | `M` или кнопка «Постранично» / «Лента» |
| Масштаб: по ширине → по высоте → 100% | `W` или кнопка масштаба («Ширина» / «Высота» / «100%») |
| Зум в режиме 100% | `+` / `−`, `0` — сброс |
| Открыть главу на mangadex.org | кнопка «Браузер» |

Горячие клавиши работают по контексту: пока открыта читалка, `Space`, `←`, `→`, `↑`, `↓`
и `N` управляют чтением, а не плеером.

**Главы без страниц.** На MangaDex встречаются главы, у которых нет картинок (например,
доступные только на сайте команды перевода) — приложение пишет об этом прямо, а не
показывает пустой экран. Такую главу можно пропустить кнопкой следующей главы.

**Прогресс чтения.** Позиция (глава, страница и место внутри страницы) сохраняется в
`manga_progress.json` — автоматически, при перелистывании и при закрытии окна. Кнопка
**«Читаю»** во вкладке «Манга» открывает список начатых тайтлов: «Продолжить» возвращает
на ту же страницу, «Забыть» — сбрасывает запись. У таких тайтлов в списке видна полоса
прочитанного.

**Кэш страниц.** Прочитанные страницы складываются в `cache\manga\pages`
(≈1 МБ на страницу): повторное открытие главы — мгновенное и без трафика. Кэш чистится
автоматически, когда превышает 300 МБ; в «Оформлении» его можно отключить.

**Если страницы не грузятся.** Страницы MangaDex отдаёт сеть MangaDex@Home
(`*.mangadex.network`); у части провайдеров эти ноды недоступны (соединение виснет,
как у shikimori.one). Приложение это замечает и качает те же страницы с
`uploads.mangadex.org` — в строке подсказки появится сообщение об этом, а страницы
продолжат загружаться. Крайний случай — кнопка «Браузер».

## Плагины

Приложение можно расширять, не трогая `main.py`: плагин — обычный файл `.py` в папке
`plugins\`. Он подхватывается при запуске, а что именно подключилось и не было ли ошибок,
видно в шапке окна: **Плагины → Список плагинов…**.

Что умеет плагин:

| Точка расширения | Что даёт |
|---|---|
| `video_sources()` | свой источник видео (свой сайт/API со ссылками на серии) |
| `manga_sources()` | свой источник манги (поиск, главы, страницы) — рядом со встроенным MangaDex |
| `themes()` | новая тема оформления в «Оформлении» |
| `actions()` | кнопки в меню «Плагины» |
| `on_started`, `on_anime_selected`, `on_playback_started`, `on_chapter_opened`, `on_closing` | реакция на события приложения |

Минимальный плагин целиком:

```python
# plugins/my_plugin.py
from main import Plugin, PluginAction


class MyPlugin(Plugin):
    name = "my-plugin"
    title = "Мой плагин"
    version = "1.0"
    author = "Ваше имя"
    description = "Что делает плагин"

    def actions(self):
        return [PluginAction("Поздороваться", self.hello)]

    def hello(self, ctx):
        ctx.status(f"Привет из плагина «{ctx.plugin.title}»!")
```

Плагин получает контекст `ctx`: версии (`ctx.version`, `ctx.api`), пути (`ctx.base_dir`,
`ctx.cache_dir`), настройки (только чтение), текущий выбор (`ctx.current_anime()`,
`ctx.current_manga()`, `ctx.current_chapter()`), сообщение в статусной строке
(`ctx.status()`), открытие ссылок и папок, а также своё хранилище `ctx.data` /
`ctx.save_data()` (файл `plugin_settings.json`). Внутренние объекты окна плагину не
выдаются — это специально: ошибка в плагине не может сломать приложение.

Ошибки изолированы: плагин, который не загрузился, виден в списке плагинов с текстом
ошибки, остальные продолжают работать; если обработчик плагина падает три раза, он
отключается и приложение продолжает работать. Подробное описание API, примеры и
правила — в `plugins\README.txt` и `plugins\_example_plugin.py`
(примеры начинаются с подчёркивания и не подключаются, пока их не переименовать).

Старый формат — источники видео в `sources_local\` — продолжает работать
(см. `sources_local\README.txt`).

## Оформление и кастомизация

Кнопка **«Оформление»** — настройки с живым превью (изменения применяются сразу):

| Настройка | Значения |
|---|---|
| Режим темы | Тёмная, Полночь (синяя), Светлая, Контрастная |
| Акцентный цвет | любой, через палитру цветов |
| Масштаб шрифта | 0.85×–1.40× |
| Высота карточек | 64–150 px |
| Постеры в списках | включить/выключить |
| Автоследующая серия | переход к следующей после окончания |
| Стартовая громкость | 0–100% |
| Читалка: режим | Лента (непрерывно), Постранично |
| Читалка: масштаб страниц | По ширине, По высоте, 100% |
| Читалка: отступ между страницами | 0–40 px |
| Читалка: английский запас | добирать главы на английском, если нет на русском |
| Читалка: кэш на диске | хранить страницы в `cache\manga` |
| Фоновые картинки | обои окна и панелей, подложка читалки и иллюстрация пустого экрана |

Сохраняется в `settings.json` (тема, акцент, масштаб, размеры окна, последний запрос,
громкость, настройки чтения) и восстанавливается при следующем запуске. Палитры —
`THEME_MODES`, сборка стилей — `build_qss()`, иконки интерфейса рисуются кодом
(`ensure_icons`), карточки — `AnimeCardDelegate`.

Минимальный размер окна — **1000×640**: при таком окне всё ещё видны плеер, читалка и
все кнопки. Если окно узкое, логотип и подпись в шапке автоматически прячутся, а подпись
текущего аниме укорачивается (полное название — во всплывающей подсказке). При большом
масштабе шрифта порог, после которого прячется логотип, растёт вместе со шрифтом.

## Картинки оформления

Все изображения интерфейса лежат в папке **`assets\`** — их можно заменить своими
(или удалить вовсе: приложение тогда просто нарисует ровный фон темы и останется
работоспособным).

| Файл | Где используется |
|---|---|
| `app_icon.ico` | иконка приложения (окно, панель задач, ярлык) |
| `app_bg.jpg` | обои окна и левой панели |
| `player_bg.jpg` | подложка панели плеера |
| `reader_bg.jpg` | подложка области чтения манги |
| `poster_placeholder.png` | заглушка постера, пока картинка не догрузилась |
| `logo_dark.png` | логотип в шапке (тёмные темы) |
| `logo_light.png` | логотип в шапке (светлая тема) |
| `empty_state.png` | иллюстрация пустого экрана читалки |
| `tag_icon.png` | метка перед подписью в карточках списков |

Как заменить: положите свои картинки в `assets\source\` под исходными именами
(`bg_app_16x9.png`, `logo_main.png` и т.д.) и выполните

```
.\runtime\python.exe tools\prepare_assets.py     — обрежет и приведёт к нужным размерам
.\runtime\python.exe tools\make_icon.py          — пересоберёт иконку приложения
```

Скрипт обрежет пустые поля, приведёт размеры к нужным, уберёт белый фон у светлого
логотипа и сложит готовые файлы в `assets\`. Оригиналы остаются в `assets\source\` —
ничего не теряется. Картинки, нарисованные однотонно (метка в карточке), приложение
перекрашивает в цвет текущей темы. Иконка приложения собирается многоразмерной
(16–256 px), поэтому выглядит чётко и в панели задач, и в проводнике.

## Горячие клавиши

Клавиши контекстные: пока справа читалка манги, `Space`, `←`, `→`, `↑`, `↓` и `N`
управляют чтением; в остальных случаях — плеером.

| Клавиши | Видео | Манга |
|---|---|---|
| `Space` | пауза / продолжить | экран вперёд |
| `←` / `→` | −10 / +10 секунд (`Shift` — по 60) | предыдущая / следующая страница |

## Скорость поиска

Замеры: список появляется примерно за 1–2 секунды (до оптимизаций было ~19 с).

* постеры не качаются последовательно — список показывается сразу, картинки
  догружаются параллельно (12 потоков) и вставляются по мере готовности;
* **гонка зеркал**: `shikimori.one` у многих провайдеров блокируется (TLS виснет),
  поэтому запрос уходит одновременно на все зеркала, берётся ответившее первое,
  а победитель запоминается в `cache/state.json`;
* при старте зеркало прогревается в фоне, пока вы печатаете название;
* автопоиск с задержкой 550 мс, кэш в памяти (повторный запрос — 0.00 с);
* отсутствие эндпоинта `/animes/{id}/episodes` у зеркал запоминается, чтобы не ждать 404.

## Источник видео

Порядок опроса: **AniLibria → ваши плагины → ваши ссылки** — побеждает первый, кто вернул ссылку.

1. **AniLibria** (`anilibria.top/api/v1`) — официальный API: поиск релиза с проверкой
   `shikimori.id`, серии с названиями, прямые HLS официального CDN.
   Сопоставление строгое: точное совпадение `shikimori.id`, затем название с порогом
   похожести 0.72 (мягкие 0.60 — только при совпадающем годе). Если тайтла нет —
   честное сообщение, чужой релиз не подставляется.
2. **`plugins\`, `sources_local\`** — ваши источники: класс-наследник `VideoSource`
   с методом `get_stream_url(anime_id, episode, dubbing)` → ссылка на поток.
   Ошибки плагина не роняют приложение.
3. **Ваши ссылки** — `manual_streams.json` (см. «Озвучки»).

## Как подключить сайт-источник

Если у вас есть сайт (например, студии озвучки), который надо подключить:

```powershell
# 1. проверить, доступен ли сайт именно из приложения (не из браузера)
.\runtime\python.exe tools\site_probe.py https://example.com

# 2. собрать данные: страницы, JS-бандлы, список API-путей
.\runtime\python.exe tools\site_probe.py https://example.com --search "название" --deep
```

Результаты складываются в `tools\probe\` (HTML, JS, `report.txt`). По ним пишется источник
по образцу `AniLibriaVideoSource`: поиск тайтла → сопоставление с Shikimori → серии →
выбор озвучки → HLS в плеер. Важно: если в отчёте `[FAIL] handshake timed out` — сайт
заблокирован по SNI, приложению нужен ваш обход блокировок или VPN.

## Технические детали

* **Встраивание mpv через `winId()`**: `mpv.MPV(wid=str(int(widget.winId())))` на QWidget
  с `WA_NativeWindow`; колбэки mpv передают данные в GUI-поток только через Qt-сигналы.
* **CA-сертификаты для mpv**: у Windows-сборки mpv нет своего бандла, поэтому HTTPS-потоки
  падали с `TLS certificate verification failed`. Бандл берётся из `certifi`
  (`find_ca_bundle()`), переопределяется переменной `ANIME_VIEWER_CA_FILE`;
  при MITM-прокси есть `ANIME_VIEWER_TLS_NO_VERIFY=1`.
* **`mpv-2.dll` лежит рядом с `mpv.py`** (в `.libs`), поэтому PATH не нужен вообще.
* **Потоки в UI**: сетевые операции — в `Worker`, постеры — в `PosterLoader`
  (пул потоков), устаревшие ответы отбрасываются по токенам; фоновые ошибки пишутся
  в статусную строку, без модальных окон.
* **Читалка манги**: страницы рисует один виджет `MangaStrip` (в `paintEvent` — только
  видимые страницы), а не по `QLabel` на страницу — глава из 60 страниц не съедает
  память и не тормозит прокрутку. Качает страницы `MangaPageLoader` (пул потоков),
  читалка только говорит, что ей нужно (`need_page`). Хост страниц определяется
  «гонкой» (нода MangaDex@Home против `uploads.mangadex.org`) и запоминается на сеанс.

## Известные ограничения

* Каталог AniLibria неполный: классика есть, часть новых тайтлов 2024–2026 отсутствует —
  приложение сообщает об этом прямо, а не подставляет другой релиз.
* Из озвучек автоматически доступна только AniLibria (см. «Озвучки»).
* Манга берётся из MangaDex: там нет всех русских переводов, поэтому часть глав
  открывается на английском (можно отключить запас — тогда не будет и их).
  Русские названия подставляются через Shikimori, и только при совпадении названий.
* Страницы MangaDex у части провайдеров недоступны напрямую: приложение качает их
  с `uploads.mangadex.org` (это происходит автоматически, см. «Манга»).
  Если недоступны оба хоста — поможет только обход блокировок или VPN.
