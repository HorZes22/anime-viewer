ПЛАГИНЫ ANIME VIEWER
================================================================================

Плагин — это обычный файл .py, который лежит в этой папке. Класть его сюда может
кто угодно: приложение подхватывает файлы автоматически при запуске, править
main.py не нужно.

Файлы, имя которых начинается с подчёркивания (_example_plugin.py), НЕ
подключаются — это примеры. Чтобы включить пример, скопируйте его под другим
именем, например my_plugin.py.

Что можно добавить плагином:

  * источники видео   — свой сайт/API со ссылками на серии;
  * источники манги   — свой сайт с главами и страницами;
  * темы оформления   — новая палитра в «Оформлении»;
  * кнопки            — пункты в меню «Плагины» в шапке окна;
  * обработчики       — реакция на события приложения (выбор тайтла, старт
                        воспроизведения, открытие главы, закрытие программы).

Как проверить, что плагин подключился: кнопка «Плагины» в шапке окна → «Список
плагинов…». Там видно, что загрузилось, что плагин добавил и какие ошибки были.
Ошибка в плагине НЕ ломает приложение: она попадает в этот список и в консоль.


МИНИМАЛЬНЫЙ ПЛАГИН
================================================================================

    from main import Plugin, PluginAction, PluginContext


    class MyPlugin(Plugin):
        name = "my-plugin"          # уникальный код (латиницей, без пробелов)
        title = "Мой плагин"        # название в списке плагинов
        version = "1.0"
        author = "Ваше имя"
        description = "Что делает плагин"

        def actions(self):
            return [PluginAction("Поздороваться", self.hello,
                                 tooltip="Проверка работы плагина")]

        def hello(self, ctx):
            ctx.status(f"Привет из плагина «{ctx.plugin.title}»!")


ВАЖНО: файл плагина импортирует классы из main.py тем же способом, каким
приложение их определяет: `from main import ...`. Ничего устанавливать не нужно.


ЧТО ПЛАГИН ПОЛУЧАЕТ: PluginContext
================================================================================

Контекст (ctx) — это единственный «мостик» между плагином и приложением.
Внутренние объекты окна плагину не выдаются, поэтому даже грубая ошибка в плагине
не может сломать интерфейс.

    ctx.version        — версия приложения (строка, напр. "1.4")
    ctx.api            — версия API плагинов (число; сверяйте со своим)
    ctx.base_dir       — папка приложения (Path)
    ctx.cache_dir      — папка кэша (Path)
    ctx.plugins_dir    — эта папка (Path)

    ctx.settings()       — копия настроек приложения (dict)
    ctx.theme()          — текущая тема оформления (dict)
    ctx.manga_settings() — настройки читалки манги (dict)

    ctx.current_anime()   — выбранный тайтл аниме или None (копия словаря)
    ctx.current_manga()   — выбранный тайтл манги или None
    ctx.current_chapter() — открытая глава манги или None

    ctx.status("текст")           — сообщение в статусной строке приложения
    ctx.open_url("https://…")     — открыть ссылку в браузере
    ctx.open_folder(path=None)    — открыть папку в проводнике (по умолчанию эту)

    ctx.data        — словарь для своих данных (сохраняется в plugin_settings.json)
    ctx.save_data() — сохранить ctx.data на диск

    ctx.plugin      — сам объект плагина


ИСТОЧНИК ВИДЕО
================================================================================

Наследник VideoSource из main.py. Обязательный метод — get_stream_url().

    from main import Plugin, VideoSource


    class MySource(VideoSource):
        name = "my-site"
        label = "Мой сайт"

        def available_dubbings(self):
            return ["Моя озвучка"]        # иначе все озвучки считаются доступными

        def get_episodes(self, anime_id):
            # необязательно: свой список серий
            return [(1, "Серия 1"), (2, "Серия 2")]

        def get_stream_url(self, anime_id, episode, dubbing):
            # ссылка на поток (mp4/m3u8) или None, если серии нет
            return f"https://example.com/anime/{anime_id}/{episode}.m3u8"


    class MyPlugin(Plugin):
        name = "my-site-plugin"
        title = "Мой сайт"
        version = "1.0"

        def video_sources(self):
            return [MySource()]

Порядок опроса источников: AniLibria → ваши источники из sources_local →
источники плагинов → ваши ссылки. Побеждает первый, кто вернул ссылку.

Приложение подсказывает источнику выбранный тайтл: он доступен в полях
self.anime_title, self.anime_title_alt, self.anime_year, self.anime_catalog_id.
Поле self.last_status — текст-пояснение, который увидит пользователь в статусной
строке, если ссылки не нашлось.


ИСТОЧНИК МАНГИ
================================================================================

Наследник MangaSource. Обязательные методы: search(), chapters(), pages().
Загрузка картинок и кэш уже готовы — переопределять их нужно только при
необходимости (пример ниже показывает, как читать локальные файлы).

    from main import MangaSource


    class MyMangaSource(MangaSource):
        name = "my-manga"          # код источника (уникальный)
        label = "Моя манга"        # название в интерфейсе
        multi_language = False     # различает ли источник языки перевода

        def search(self, query, limit=24, langs=None):
            # [{"id", "title", "title_alt", "year", "status", "last_chapter",
            #   "poster_url", "langs", "description"}, ...]
            return [...]

        def chapters(self, manga_id, langs=("ru", "en")):
            # [{"id", "chapter", "volume", "title", "lang", "lang_label",
            #   "group", "pages"}, ...]
            return self.fit_chapters([...])   # сортировка и чистка — готовый помощник

        def pages(self, chapter_id):
            return ["https://example.com/01.jpg", "https://example.com/02.jpg"]

        # необязательно: ссылка для кнопки «В браузере…»
        def chapter_web_url(self, chapter_id):
            return f"https://example.com/chapter/{chapter_id}"

Подключение — тем же способом, что и видео:

    def manga_sources(self):
        return [MyMangaSource()]

Если источник манги в плагине один, в приложении появится выбор источника над
списком манги. У каждого источника свой прогресс чтения: записи не путаются,
даже если идентификаторы тайтлов совпадут.

КАТАЛОГ ТАЙТЛОВ (НЕОБЯЗАТЕЛЬНО)
================================================================================

Вкладка «Манга» умеет показывать готовый список всех тайтлов источника — без поиска.
Чтобы дать приложению такой список, добавьте в свой MangaSource:

    class MyMangaSource(MangaSource):
        supports_catalog = True              # включаем каталог
        catalog_sorts = {                    # что предложить в списке сортировок
            "popular": "Популярные",
            "title": "По названию",
        }

        def catalog(self, offset=0, limit=40, sort="popular", only_russian=False):
            """Вернуть (тайтлы, всего_в_каталоге)."""
            items = self._fetch(offset=offset, limit=limit, sort=sort,
                                only_russian=only_russian)
            return items, self._last_total

Если supports_catalog не указан (по умолчанию False), элементы каталога в интерфейсе
выключаются и приложение предлагает поиск — это нормально для источников, у которых
нет «всего списка».

Словари тайтлов — того же вида, что и в search(). Приложение само листает каталог:
«Показать ещё» вызывает catalog() со следующим offset, поэтому метод должен
поддерживать offset и limit.

Загрузка страниц идёт в ФОНОВЫХ потоках: методы search(), chapters(), pages() и
download_page() вызываются не в потоке интерфейса. Поэтому в них нельзя трогать
окно и нельзя пользоваться QPixmap — для картинок в потоке берите QImage, а
результат возвращайте байтами.

Рабочий пример источника манги, который сам рисует страницы (его можно скопировать
под другим именем и заменить на запросы к своему сайту) — plugins/_example_manga_source.py.


ТЕМЫ ОФОРМЛЕНИЯ
================================================================================

Тема — словарь с палитрой. Достаточно задать цвета, остальное приложение
досчитает само (оттенки акцента, размеры шрифтов берутся из масштаба).

    def themes(self):
        return {
            "my-sunset": {
                "title": "Закат",              # название в списке тем
                "bg": "#1a1016", "panel": "#241a22", "card": "#2b1f29",
                "card_hover": "#33242f", "text": "#ffeee8", "muted": "#b08f9c",
                "border": "#3a2b34", "input": "#241a22", "input_focus": "#2b1f29",
                "player": "#120a10",
            }
        }

Встроенные темы (dark, midnight, light, contrast) плагин перекрыть не может —
такая тема будет пропущена с предупреждением в списке плагинов.


КНОПКИ
================================================================================

    from main import Plugin, PluginAction

    def actions(self):
        return [
            PluginAction("Открыть сайт", self.open_site, tooltip="…", needs="anime"),
            PluginAction("Ещё что-то", self.other),
        ]

    def open_site(self, ctx):
        anime = ctx.current_anime() or {}
        ctx.open_url("https://example.com/search?q=" + str(anime.get("title", "")))

Поле needs: "anime" — кнопка доступна только когда выбран аниме-тайтл,
"manga" — когда выбран тайтл манги, "" — всегда.

    def on_anime_selected(self, anime):

СВОИ ДАННЫЕ
================================================================================

    def on_started(self, ctx):
        self.ctx = ctx
        self.count = int(ctx.data.get("count", 0)) + 1
        ctx.data["count"] = self.count
        ctx.save_data()

Файл plugin_settings.json лежит рядом с программой, у каждого плагина в нём свой
раздел — плагины не мешают друг другу и не трогают настройки приложения.


ЧЕГО НЕ СТОИТ ДЕЛАТЬ
================================================================================

  * Долгие операции (сеть, ожидание) прямо в on_* и в кнопках: они выполняются в
    потоке интерфейса, поэтому приложение «задумается». Если нужно долго — делайте
    это в своём потоке и возвращайте результат через ctx.status().
  * Патчить внутренние объекты окна (ctx._app.…): они могут измениться в новой
    версии приложения, а плагин после этого сломается.
  * Печатать в консоль поток ошибок — используйте ctx.status().

Проверка перед публикацией: запустите приложение с плагином, откройте «Плагины →
Список плагинов», убедитесь, что там нет ошибок и предупреждений.
